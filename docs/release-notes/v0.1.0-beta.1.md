# swift-client v0.1.0-beta.1 (pre-release)

> Released as a pre-release: https://github.com/zht7063/portable-agent-client/releases/tag/v0.1.0-beta.1

## English

**This is a pre-release (beta) for testing. Do not rely on it for production work.**

swift-client is a desktop client for [new-api](https://github.com/QuantumNous/new-api) servers. It uses the upstream
new-api web frontend (vendored and patched), keeps API keys in the operating system keychain, and can configure local
coding agents (Pi, Claude Code, Codex) to use your server.

### Signing

- **Windows:** not code-signed. SmartScreen may warn "Windows protected your PC"; choose *More info* → *Run anyway*
  only if the checksum matches.
- **macOS:** ad-hoc signed only (`codesign --sign -`; no Developer ID certificate, not notarized). Gatekeeper will block the first launch: open
  *System Settings → Privacy & Security* and choose *Open Anyway*, or run
  `xattr -dr com.apple.quarantine /Applications/swift-client.app`.

### Verify the download

- macOS / Linux: `shasum -a 256 -c swift-client-0.1.0-beta.1-mac-arm64.dmg.sha256`
- Windows (PowerShell): `Get-FileHash .\swift-client-0.1.0-beta.1-win-x64.exe -Algorithm SHA256` and compare the
  hash with the one in the `.sha256` file.

### Known limitations

- **No settings migration after the rename:** settings from earlier test builds (under the previous name) are not
  migrated. After installing swift-client you must sign in and configure the server and coding agents again.
- Pre-release: settings and stored data may change incompatibly before 1.0.
- Unsigned (Windows) / ad-hoc signed (macOS) builds; expect OS security prompts on first launch.
- No auto-update; install new versions manually.
- Linux packages are not part of this pre-release.
- Requires access to a new-api server; compatibility is tested against the versions listed in `compat.json`.
