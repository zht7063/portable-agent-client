# swift-client v0.1.0-beta.2 (pre-release)

> Pre-release: https://github.com/zht7063/portable-agent-client/releases/tag/v0.1.0-beta.2
> (tag `v0.1.0-beta.2` on commit `<RELEASE_COMMIT — fill after merge>`).

## English

**This is a pre-release (beta) for testing. Do not rely on it for production work.**

### What's new

- **Server configured:** fixed build-time origin `http://185.115.207.247:3000` (cleartext; see the warning above).
  Settings show it read-only, and the app shows an "insecure transport" warning.
- **Harness config:** one-click configuration of Codex CLI (`--profile swift`, bearer token) and Claude Code
  (`env.ANTHROPIC_AUTH_TOKEN`). Changes are previewed, ownership-tracked and reversible with scoped rollback/detach.
  Keys are stored in a plaintext key file protected by private file permissions. Plans warn about cleartext HTTP.
- **Shop tab:** an isolated in-app shop view (`persist:shop` session, sandboxed, no preload). Navigation outside the
  shop is blocked silently; "Open in browser" hands links to your browser.
- **beta.1 migration:** on first launch, legacy `apiKeyHelper` / `pa-key` references and provider `pa` are found and,
  after you confirm, removed. Your previous address and model settings are restored, or removed if they did not exist
  before. Select a token again on the Harness page afterwards.

### Known limitations

- **Cleartext HTTP** (see the top of these notes).
- Server APIs are untested against the live server until rain recovers. The server reports new-api v1.0.0-rc.47; this build is tested up to rc.46 (shown as "untested").
- L3 (paid) connectivity tests are disabled.
- Windows file ACLs and the beta.1 → beta.2 upgrade/uninstall path are unverified on real machines.
- The real shop and payment flows are unverified.
- In-app login may fail if the server marks its session cookie `Secure` (dropped over HTTP; unverified).
- Static bundle scan (check-asar) does not yet catch some obfuscated env/URL forms (`global.process`, `require('process')`,
  `(0, process).env`, `Reflect.get`, split template protocols, `join`/`fromCharCode` URLs); runtime origin pinning still applies.
- Remaining Aegis r40 low-priority items are tracked as follow-ups.
- Unsigned/ad-hoc builds, no auto-update, no Linux packages. Settings may change incompatibly before 1.0.
